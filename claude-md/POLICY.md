# Model Routing

Keep the explicitly selected or already-capable session model. For new complex
Claude work, Claude Opus 5 is a starting candidate; reserve available Fable models
for unresolved judgment gaps. Codex can own work end to end too. GPT-5.6 Sol and
GPT-6 Astra are optional peers for distinct tasks, subject to client availability.

Use the configured effort unless a task or evaluation justifies changing it.
Model and effort recommendations do not switch a session. Use supported native
controls and distinguish requested from observed model identity.

Run deterministic checks before independent review. The primary owner verifies
findings and integrates changes regardless of provider. A review verdict does
not grant authority to merge, publish, deploy, or expand permissions.

Use compact handoffs only when context must move. Delegate independent packets
only when useful and authorized. Keep worker depth bounded and stop after two
rounds without progress. Load `/claude-model-optimizer` for detailed policy,
host-specific guidance, and optional discovery or review-receipt helpers.
